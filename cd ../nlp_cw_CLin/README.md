# NLP CW: Patronising and Condescending Language (PCL)

## Where to find the predictions

The predictions generated by the model are located in the **root directory** of this project:

- `dev.txt`: Predictions for the official dev set
- `test.txt`: Predictions for the official test set

### Exploratory Data Analysis (EDA)

In `eda/` directory, contains `eda.ipynb` containing analysis of data

## Training of the model

Training pipeline is located in `BestModel/` directory

### Hyperparameter Tuning

Large grid search to find optimal hyperparameters

- **Script:** `BestModel/hyperparameter_script.py`
- **Execution:** Run via `BestModel/hyperparam_grid_search_script.sh` on the gpucluster
- **Output:** The results of all runs and the optimal threshold are saved to `BestModel/grid_results.csv`

### Final Model Training

Once the best hyperparameters were identified, the final model was trained on the full training set

- **Script:** `BestModel/model.py`
- **Execution:** Run via `BestModel/model_script.sh` on the gpucluster
- **Output:** The fully trained model is saved to `BestModel/final_model/`

### Evaluation and Error Analysis

Local evaluation, ablation studies, and error analyses are contained in the `Eval_and_Error/` directory

- **Generating Predictions:** The `Eval_and_Error/evaluation.py` script (executed via `evaluation_script.sh` on the gpucluster) loads the saved model from `BestModel/final_model/`, applies the tuned threshold, and outputs the `dev.txt` and `test.txt` files to the root directory
- **Ablation Study:** Quantifies impact of the data augmentation pipeline, `Eval_and_Error/ablation_studies.py` trains a model using the same base hyperparameters but without any data augmentation
- **Error Analysis:** `Eval_and_Error/error_analysis.ipynb` extracts false positives and false negatives and generates a visualisation

### Source Code

The `src/` directory contains the functions used across the repository

- `augment.py`: Logic for data augmentation
- `data_utils.py`: Downloading datasets
- `trainer.py`: Hugging Face `WeightedTrainer` subclass
- `eval.py`: For metrics used during training
